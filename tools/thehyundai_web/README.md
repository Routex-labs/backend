# 더현대 서울 공개 웹 → 매장 상세 오버레이

도면(Studio)에는 매장의 **기하와 이름·분류뿐**이라 소개글·영업시간이 없다. 그 빈자리를
더현대 서울 공식 사이트에서 받아 `src/main/resources/store_details/`의 오버레이로 바꾸는
도구다.

```bash
python tools/thehyundai_web/extract.py tools/thehyundai_web/snapshot   # 받아 온다
python tools/thehyundai_web/build_overlays.py 2026-08-22               # 오버레이로 바꾼다
```

두 단계로 나눈 이유는 사이트가 바뀌었을 때 **받는 쪽이 깨진 것인지 고르는 쪽이 깨진
것인지** 구분하기 위해서다. `snapshot/`은 받은 그대로이고 커밋한다 — 나중에 값이
달라졌을 때 사이트가 바뀐 것인지 우리가 규칙을 바꾼 것인지 비교할 것이 있어야 한다.

확인일을 인자로 받는 것도 같은 이유다. 코드가 `오늘`을 스스로 정하면 아무도 확인하지
않은 날짜가 `confirmed_at`에 박힌다.

## 어디서 무엇이 나오나

| 원천 | 나오는 것 | 건수 |
|---|---|---|
| `/store/restaurants` | 식당 이름·층·전화·영업시간·브레이크타임·라스트오더·소개글·사진 | 63 |
| `/api/floor-brands?floorCode=` | 층별 브랜드 이름·전화·brandCode·구획 | 534 |
| `/api/dining/menu?…` | 식당 메뉴 이름·설명·가격·사진 | 186 |
| `/about/facilities` | 편의시설 이름·층·소개글·사진 | 19 |

앞 셋은 JSON이고 `/about/facilities`만 React 엘리먼트 트리라 카드 단위로 잘라 읽는다.

## 지금 오버레이로 나가는 것

식당 **47건**(소개글 + `hours`)과 편의시설 **25건**(소개글). 도면 id와 짝지어진 수이지
사이트에 있는 수가 아니다.

- 이름이 서로 다른 것은 `build_overlays.py`의 별칭표가 잇는다(`강호연파` ↔
  `강호연파 밥굽남`). 도면에 아예 없는 곳(`아르켓 카페`·`더닝`·`클럽웨딩`)은 안 나간다.
- **이미 손으로 써 둔 오버레이가 있는 id는 건너뛴다**(15건). 로더는 같은 id가 두 파일에
  있으면 나중 파일이 이기므로, 사진·메뉴까지 채운 수작업본을 소개글만 있는 자동
  생성본이 덮을 수 있다.

## 받아 두고도 안 싣는 것

`_schema.json`이 막거나, 실어 두면 낡는 값이다. 안 싣는 이유를 여기 적어 두는 것은
다음 사람이 같은 길을 다시 파지 않게 하기 위해서다.

| 안 싣는 것 | 이유 |
|---|---|
| 전화번호 534건 | `forbidden_labels`가 `keyValue`·`businessInfo` 양쪽에서 막는다. `hours` 같은 검증된 구조체 자리도 없다 |
| 라스트오더 | 같은 이유. `hours` 구조체에 자리가 없다 |
| 사진·메뉴 | `hero.local_asset`·`menu.image_asset`이 **앱 번들 경로**라 원격 URL을 그대로 못 넣는다. 이미지를 클라이언트 저장소에 받아 넣는 것이 선행 작업이다 |
| 휴점일 | 사이트가 요일 규칙으로 공지하지 않는다. 요일에서 유추하면 확인되지 않은 값이 확인된 값과 같은 모양으로 저장된다 |

## 일반 브랜드에는 소개글이 없다 — 사이트 문제가 아니다

식당이 아닌 브랜드 471곳은 이름·전화·구획이 전부다. 현대백화점 레거시 포털까지
따라가 확인했다.

- 층별 안내(`/newPortal/DP/FG/FG000000_V.do`)의 브랜드 한 줄에는 이름·전화·`map_brand_cd`만
  있고, 상세를 펼치는 `getDiningInFloor.do`는 **식당에만 답한다** — 일반 브랜드
  코드로 부르면 `[[],[],[]]`가 돌아온다.
- 그 엔드포인트가 주는 소개글·사진 5장·메뉴는 새 사이트의 `/api/dining/menu`와
  `/store/restaurants`가 이미 같은 값을 준다(사진도 최대 5장까지 그대로 나온다).

즉 일반 브랜드의 소개글은 **현대 쪽에 원래 없다.** 채우려면 브랜드 공식 페이지에서
사람이 옮겨 오는 수밖에 없고, 그것이 기존 수작업 오버레이가 하던 일이다.
