# FastAPI ↔ Spring 대응표

원본: [Routex-labs/Navigation](https://github.com/Routex-labs/Navigation) `backend/`

이 문서의 목적은 하나다 — **"이 파이썬 파일이 어디로 갔나"에 한 줄로 답하는 것.**
이식 중간에 이걸 못 하면 길을 잃는다.

| `app/models/building.py` `Floor` | `spring/building/domain/Floor.java` |

## 옮기면서 바꾼 것

**좌표 타입을 엔티티와 DTO가 공유한다.** 파이썬은 ORM(JSON 컬럼)과 Pydantic 모델이
따로였지만, `{"x":…,"y":…}`로 모양이 같고 갈라질 이유가 없어 `LocalPoint` 하나로 뒀다.
갈라지면 그때 나눈다.

**상세 응답이 요약을 상속하지 않는다.** 파이썬은 `BuildingDetailResponse(BuildingSummaryResponse)`
지만 자바 레코드는 상속이 없다. JSON은 어차피 평평해야 하므로 필드를 그대로 다시 적었다.

**`Floor`는 컬럼을 다 매핑하지 않는다.** 지금은 `name`·`level`만 쓴다. 도면 외곽선
(`footprint_local_m`)과 비보행 폴리곤(`non_walkable_polygons_local_m`)은 `floormap` 패키지를
이식할 때 더한다 — 안 쓰는 컬럼을 미리 매핑하면 어느 쪽이 진짜 계약인지 흐려진다.

코드에는 `ponytail:` 주석으로 표시해 뒀다.
